# D-0001｜正式 MVP 使用 FastAPI 单体后端

日期：2026-09-29  
状态：Accepted

## 决定

V1.0 使用 Python 3.12 + FastAPI 单体业务服务，不采用 Spring Boot 业务服务 + Python OCR 双后端，也不采用微服务。

## 原因

- OCR PoC 已使用 Python 并验证；
- 当前用户规模和团队规模小；
- 减少语言/服务/部署数量；
- 当前核心难点是 OCR 安全确认闭环，不是服务拆分。

## 影响

微信小程序和 Admin 共用同一业务 API；OCR 仍作为独立 Worker 进程，但不是独立微服务体系。

## 重新评估条件

单体维护出现明确边界问题或业务规模发生实质变化。
